# mimotion

通过 Zepp Life（原小米运动）API 修改步数。

### 操作流程

1. 输入 Zepp Life 账号
2. 输入密码
3. 输入目标步数（直接回车使用默认值 35000）
4. 等待上传结果

## 注意事项

- 请确保 Zepp Life 账号已绑定微信运动
- 步数上传后可能需要等待几分钟同步到微信
- 请勿频繁上传大量步数，以免账号异常
